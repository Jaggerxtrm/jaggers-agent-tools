# XTRM updates and dependencies

Use `xt update`/current maintenance commands in dry-run/report mode before apply where the
CLI supports it. Inspect release notes and local drift; do not overwrite user-owned
skills/configuration merely to make the fleet uniform.

For dependency upgrades, understand the behavioral/API delta and test the affected XTRM
surface, not only lockfile resolution. Keep generated/runtime views derived from their
canonical sources.
