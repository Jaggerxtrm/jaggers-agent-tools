# GitNexus CLI and resources

Use the installed GitNexus help/resources for exact command names and schemas. Typical
needs are repository indexing/analysis, index status/listing, concept queries, symbol
context, impact analysis, and graph/schema inspection.

If the index is stale, refresh it before relying on absence-of-reference claims.

Prefer MCP/native tools when the current agent has them because structured results are
easier to consume. Use CLI as the portable fallback. Do not preserve a duplicate static
command reference here; the tool evolves independently of XTRM.
