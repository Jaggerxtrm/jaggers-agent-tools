# Exploring with GitNexus

1. Query the concept or user-visible flow.
2. Identify the relevant process/community and candidate symbols.
3. Get context for the smallest set of symbols that explain the flow.
4. Read only the source ranges needed to confirm behavior.
5. Follow calls/imports only where the current question requires it.

Output should distinguish graph evidence, source-confirmed facts, and remaining unknowns.
Do not dump an entire repository into context because a graph query returned many hits.
